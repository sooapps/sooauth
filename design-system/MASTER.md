# sooauth design system — MASTER

Deep navy, canvas white, sage surfaces, and a lime-yellow action accent.

## Accent — exactly one

**`#E8FF3F`** lime-yellow on deep navy. Hover `#BAE02D`. Active `#E8FF3F`.

Semantic status (ok / warn / error) is not brand. Never let success green become chrome.

## Surfaces

| Token | Hex | Use |
| --- | --- | --- |
| canvas | `#FFFFFF` | Page background |
| primary | `#051B23` | Text, borders, primary actions |
| surface | `#F5F5F5` | Cards and panels |
| surface-alt | `#E3EFD7` | Section bands and email background |
| neutral | `#C4C4C4` | Hairline borders |
| muted | `#5D6B70` | Secondary text |

## Typography

Switzer / system sans for body copy and pxGroteskMono / ui-monospace for actions.

## Hard avoid

- AI purple-pink gradients, glassmorphism, sparkles
- Emoji as icons (Lucide only)
- 3-column icon grid hero
- Orange second CTA

## Pages

- Hosted auth pages: flawless mobile, password managers, passkey UI
- Admin: dense, keyboard-first
- Marketing: product frame of real login flow, GSAP scroll
