# Roadmap

Sooauth is developed in public by Sooapps. Priorities can change as teams use
the product; security fixes and protocol correctness take precedence.

## Launch track

- [x] Standard OIDC discovery, authorization, token, userinfo, and JWKS
- [x] Hosted email authentication and verification
- [x] Google and GitHub login
- [x] Passkeys
- [x] Embed widget and JavaScript SDK
- [x] Self-host deployment path
- [x] TOTP MFA for platform accounts
- [ ] Guided first-project onboarding
- [ ] End-user security center
- [ ] Webhooks with signed deliveries and retry
- [ ] Auth activity analytics

## Next

- [ ] Account linking across email, social, and passkey credentials
- [ ] Framework starter repositories
- [ ] Auth.js, Auth0, and Clerk migration assistant
- [x] Hosted Sooauth beta at `auth.sooauth.com`
- [ ] Managed Cloud plans with documented limits and support tiers
- [ ] Public status and incident history

## Later

- [ ] Organizations and team invitations
- [ ] Organization roles and advanced RBAC
- [ ] SAML SSO and SCIM provisioning
- [ ] Audit export and compliance packages
- [ ] Native mobile SDKs

Open an issue or discussion on GitHub with the problem you are trying to solve,
not only the feature name.
