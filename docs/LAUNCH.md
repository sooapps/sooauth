# Launch Checklist

## Product Hunt / Betalist

- [ ] Confirm the public hosted signup URL: `https://auth.sooauth.com/auth/sign-up`.
- [ ] Record the 60-second flow: create project, copy OIDC values, sign in.
- [ ] Capture hosted login, Security Center, dashboard, and self-host screens.
- [ ] Publish the Next.js example and link it from the README.
- [ ] Publish the comparison pages for Auth0 and Clerk.
- [ ] Publish the changelog and public roadmap.
- [ ] Add a public status page and incident contact.
- [ ] Prepare launch-day support coverage and response templates.
- [ ] Ask early users for permission before publishing testimonials.

## Positioning

Use one sentence consistently:

> Sooauth is open-source authentication you can use at auth.sooauth.com or
> self-host: standard OIDC, passkeys, social login, and hosted auth pages.

Mention Sooapps as the company behind the product, not as a second product name.
